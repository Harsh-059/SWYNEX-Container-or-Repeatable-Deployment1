# SWYNEX Containerization Project

## Project Description

This project demonstrates how to containerize a simple Bash Calculator application using Docker.

The application performs:
- Addition
- Subtraction
- Multiplication
- Division

## Technologies Used

- Ubuntu
- Bash
- Docker
- Git
- GitHub
